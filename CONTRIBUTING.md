# Contributing to AI 3D Studio

Contributions are welcome — bug reports, docs, tests and code.

1. Read the [contributing guide](docs/CONTRIBUTING_GUIDE.md) (ground rules,
   repository map, required checks) and [installation guide](docs/INSTALLATION.md).
2. For anything larger than a small fix, open an issue first so we can agree on
   the approach and which phase of the [roadmap](docs/IMPLEMENTATION_ROADMAP.md)
   it belongs to.
3. Make sure every check in the guide passes, add tests for new behaviour and
   update the docs you touched.
4. By contributing you agree your work is licensed under the
   [Apache License 2.0](LICENSE), and you agree to follow the
   [Code of Conduct](CODE_OF_CONDUCT.md).

Security issues: please follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
